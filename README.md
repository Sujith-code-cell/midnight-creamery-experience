# 🍦 Midnight Creamery

A premium luxury ice cream website built with modern web technologies and designed to deliver an immersive, high-end user experience.

## ✨ Features

- Modern luxury UI/UX
- Responsive design for all devices
- Premium flavor showcase
- Interactive product cards
- Smooth animations and transitions
- Glassmorphism effects
- Flavor of the Day section
- Customer testimonials
- Contact and location information
- Shopping cart experience
- Mobile-first design

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite

## 📸 Preview

Experience handcrafted ice cream flavors through an elegant and immersive digital experience.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
